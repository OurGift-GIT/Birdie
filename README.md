# 🚁 Helicopter Combat: Little Bird

3D игра на Three.js где вы управляете боевым вертолетом Little Bird, уворачиваетесь от ракет и уничтожаете зенитные установки.

## 🎮 Особенности

- **Реалистичная физика полета** с управлением через наклоны (roll, pitch, yaw)
- **Вертолет Little Bird** с двумя миниганами
- **Камера от третьего лица** с плавным следованием
- **Город с невысокими зданиями** для тактического низколетного полета
- **Зенитные установки (AAA)** с системой наведения
- **Ракеты с ограниченным углом доворота** - не могут развернуться на 180°
- **Физика коллизий** - ракеты взрываются о здания
- **Система очков и выживания**

## 🎯 Геймплей

Ваша задача - уничтожить как можно больше зенитных установок и выжить максимально долго. Используйте здания как укрытие - ракеты не проходят сквозь них. Летайте низко между зданиями, чтобы затруднить наведение ракет.

### Механика ракет

Ракеты имеют ограниченный угол доворота (`maxTurnRate = 2.5 рад/сек`), поэтому:
- Не могут мгновенно развернуться
- Можно увернуться резким маневром
- Здания блокируют их траекторию
- Низкий полет между зданиями - лучшая тактика

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| **W** | Увеличить тягу (вверх) |
| **S** | Уменьшить тягу (вниз) |
| **A** | Поворот влево (yaw) |
| **D** | Поворот вправо (yaw) |
| **←** | Крен влево (roll) |
| **→** | Крен вправо (roll) |
| **↑** | Наклон вперед (pitch) |
| **↓** | Наклон назад (pitch) |
| **Пробел** | Стрельба из миниганов |
| **Shift** | Турбо ускорение |

## 🚀 Запуск

Игра использует ES6 модули, поэтому необходим локальный веб-сервер:

### Вариант 1: Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

### Вариант 2: Node.js
```bash
npx http-server
```

### Вариант 3: VS Code
Установите расширение "Live Server" и запустите через него.

Затем откройте в браузере:
```
http://localhost:8000
```

## 🏗️ Архитектура кода

### Основные классы

- `Helicopter` - вертолет с физикой полета
- `City` - генерация города и проверка коллизий
- `AAA` - зенитная установка
- `Missile` - самонаводящаяся ракета с ограниченным углом доворота
- `Bullet` - пули из миниганов

### Физика

- Гравитация и тяга
- Наклоны влияют на направление движения
- Автостабилизация при отсутствии ввода
- Сопротивление воздуха
- Столкновение с землей

## 🎯 Советы для игры

1. **Летайте низко** - чем ближе к земле, тем сложнее ракетам вас достать
2. **Используйте здания** - прячьтесь за ними от ракет
3. **Резкие маневры** - ракеты не могут быстро развернуться
4. **Управляйте тягой** - держите баланс между высотой и маневренностью
5. **Турбо в критических ситуациях** - используйте Shift для быстрого ухода
