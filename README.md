# 🚁 Helicopter Combat: Little Bird

3D игра на Three.js где вы управляете боевым вертолетом Little Bird, уворачиваетесь от ракет и уничтожаете зенитные установки.

## 🎮 Особенности

- **Реалистичная физика полета** с управлением через наклоны (roll, pitch, yaw)
- **Вертолет Little Bird** с двумя миниганами
- **Камера от третьего лица** с плавным следованием
- **Город с невысокими зданиями** для тактического низколетного полета
- **Зенитные установки (AAA)** с системой наведения
- **Ракеты с ограниченным углом доворота** - не могут развернуться на 180°
- **Физика коллизий** - ракеты взрываются о здания
- **Система очков и выживания**
- **📱 Полная поддержка мобильных устройств**:
  - Виртуальные джойстики с тач-управлением
  - DeviceOrientation API для тилт-контролов
  - Адаптивный UI для горизонтальной ориентации
  - Поддержка iOS 13+ с запросом разрешений

## 🎯 Геймплей

Ваша задача - уничтожить как можно больше зенитных установок и выжить максимально долго. Используйте здания как укрытие - ракеты не проходят сквозь них. Летайте низко между зданиями, чтобы затруднить наведение ракет.

### Механика ракет

Ракеты имеют ограниченный угол доворота (`maxTurnRate = 2.5 рад/сек`), поэтому:
- Не могут мгновенно развернуться
- Можно увернуться резким маневром
- Здания блокируют их траекторию
- Низкий полет между зданиями - лучшая тактика

## ⌨️ Управление

### Клавиатура (Desktop)

| Клавиша | Действие |
|---------|----------|
| **W** | Увеличить тягу (вверх) |
| **S** | Уменьшить тягу (вниз) |
| **A** | Поворот влево (yaw) |
| **D** | Поворот вправо (yaw) |
| **←** | Крен влево (roll) |
| **→** | Крен вправо (roll) |
| **↑** | Наклон вперед (pitch) |
| **↓** | Наклон назад (pitch) |
| **Пробел** | Стрельба из миниганов |
| **Shift** | Турбо ускорение |

### 📱 Мобильное управление

Игра полностью адаптирована под мобильные устройства!

#### Виртуальные джойстики

- **Левый джойстик** (слева внизу):
  - **Вверх/Вниз**: Тяга вертолета
  - **Влево/Вправо**: Поворот (yaw)

- **Правый джойстик** (справа внизу):
  - **Все направления**: Крен и тангаж (roll/pitch)

#### Кнопки действий (справа по центру)

- **🔫 Кнопка стрельбы**: Огонь из миниганов
- **⚡ Кнопка турбо**: Ускорение

#### Тилт управление (датчики устройства)

- Нажмите **"📱 Включить тилт"** вверху экрана
- На iOS 13+ потребуется разрешение на использование датчиков
- **Наклоняйте устройство** для управления креном и тангажом
- Тилт **заменяет** правый джойстик для более реалистичного управления

#### Ориентация экрана

- **Обязательно используйте горизонтальную ориентацию (landscape)**
- При вертикальной ориентации появится предупреждение
- Поверните устройство горизонтально для начала игры

## 🚀 Запуск

Игра использует ES6 модули, поэтому необходим локальный веб-сервер:

### Вариант 1: Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

### Вариант 2: Node.js
```bash
npx http-server
```

### Вариант 3: VS Code
Установите расширение "Live Server" и запустите через него.

Затем откройте в браузере:
```
http://localhost:8000
```

## 🎯 Советы для игры

### Общие
1. **Летайте низко** - чем ближе к земле, тем сложнее ракетам вас достать
2. **Используйте здания** - прячьтесь за ними от ракет
3. **Резкие маневры** - ракеты не могут быстро развернуться
4. **Управляйте тягой** - держите баланс между высотой и маневренностью
5. **Турбо в критических ситуациях** - используйте для быстрого ухода

### Для мобильных устройств
1. **Используйте тилт** - это более интуитивно и быстрее, чем джойстики
2. **Держите устройство горизонтально** - так удобнее и лучше обзор
3. **Калибруйте тилт** - включите его, держа устройство комфортно
4. **Большие пальцы на джойстиках** - используйте удобный хват
5. **Стреляйте указательным** - так проще управлять одновременно
